Q1 : Différences React (Vite) vs Next.js
React (Vite)
Structure centrée sur src/
Routing géré dans le code (App.tsx + react-router-dom)
Tout est côté client (CSR)
Next.js
Structure basée sur app/
Routing basé sur les dossiers (file-based routing)
Support Server Components (SSR)
 Différence  :
React = routing programmation
Next.js = routing structure des fichiers
 Q2 : Nombre de fichiers pour /login
Next.js : 1 seul fichier
 app/login/page.tsx
React Router :
1 composant
1 route dans App.tsx
1 import
Next.js est beaucoup plus simple et rapide
 Q3 : Récupération de l’id
React : useParams() (hook client)
Next.js : params passé en props depuis le serveur
Différence fondamentale :
React = côté client
Next.js = côté serveur (SSR)
